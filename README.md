# inoex-weblog

INOex 웹하드(시놀로지 NAS) 로그 자동 수집용 프로그램 배포 저장소입니다.

- `inoex_webhard_setup.sh` — NAS 가 매일 새벽 내려받아 실행하는 설치·수집 스크립트(프로그램 코드가 안에 들어 있음).
- `stub_for_dsm.sh` — 작업 스케줄러 칸에 넣는 짧은 스크립트. 위 파일을 내려받아 실행합니다.

이 저장소에는 프로그램 코드만 있습니다. 비밀키, 계정, IP, 로그 데이터는 들어 있지 않고, 수집한 원본 로그는 NAS 안에만 남습니다.
이 파일은 자동 생성됩니다. 직접 고치지 마세요.
